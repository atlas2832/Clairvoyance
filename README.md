# Clairvoyance

A Forge 1.20.1 mod adding a legit block-ESP item: registered blocks render through walls.

- Right-click: settings, Shift + right-click: on/off (keys available, unbound by default)
- Per-block color, mode (Both/Outline/Fill) and distance, editable in the GUI
- Curios slot supported when installed

Config: `panelWidthRatio`, `maxSuggestionsShown`, `maxScanDistance`, `outlineWidth`, `scanIntervalTicks`
